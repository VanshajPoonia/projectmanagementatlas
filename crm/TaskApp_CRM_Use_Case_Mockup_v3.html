Primary Users

  • Intake User: creates clients and orders.
  • Operations User: manages assignments and statuses.
  • Manager: monitors aging, workload, bottlenecks and exceptions.
  • Administrator: runs organization-wide reporting and manages configuration.

Core Data Objects

  • Client / Account
  • Contact
  • Order / Case / Job
  • Status History
  • In Progress User / Department
  • Notes / Activities
  • Documents / Attachments
  • Closure / Disposition

Reporting Principle

Do not merely store the current status. Store every status transition with an entered timestamp, exited timestamp, user, and reason. That turns routine workflow activity into measurable operational data.

Operational Use Cases

UC-01Create a new client record with contact information, source, owner, and notes.
UC-02Create an order and associate it to an existing or newly created client.
UC-03Assign an order to an employee, team, or department.
UC-04Advance, hold, reopen, or close an order using controlled status values.
UC-05Capture notes, documents, tasks, and contact activity throughout the lifecycle.
UC-06Search and filter clients and orders by status, owner, date, priority, source, or order type.
UC-07Alert users and managers when orders exceed a status-time or completion-time target.

Administrative Reporting Use Cases

RPT-01Measure New → Closed total cycle time.
RPT-02Measure any Status A → Status B elapsed time.
RPT-03Measure average, median, minimum, maximum, and percentile cycle times.
RPT-04Measure average time spent inside each individual status.
RPT-05Compare cycle times by employee, team, department, order type, source, or client segment.
RPT-06Identify aging orders currently stuck in a status beyond a defined threshold.
RPT-07Measure order-entry volume, closure volume, backlog growth, and closure rate.
RPT-08Measure SLA / target completion compliance and reasons for missed targets.
RPT-09Identify workflow bottlenecks by longest stage duration and most frequent delay reason.
RPT-10Export filtered reporting data for CSV, spreadsheet, or external BI use.
